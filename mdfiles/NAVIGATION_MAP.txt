KEY CONCEPT: CONTEXT-BASED RULE SELECTION
────────────────────────────────────────────────────────────────────────────────

What "Context-Based" Means:
──────────────────────────
• You DON'T see a fixed list of all 400+ rules
• You SEE ONLY rules found in YOUR manuscript
• System analyzes YOUR text and shows what's there
• You choose which found rules to apply
• Each rule shows where it appears in YOUR chapters

Example:
────────
Manuscript Analysis Results:
  ✓ 47 different rule types found in your 11 chapters
  ✓ 2,592 total occurrences

Discovery shows you:
  "Figure Caption"           → Found 12 times (show in Ch01, Ch02, Ch05)
  "Figure Citation"          → Found 31 times (show in Ch01-Ch10)
  "Percent with % sign"      → Found 127 times (show everywhere)
  ... (44 more rules)

You select:
  ☑ Figure Caption (12)
  ☑ Figure Citation (31)
                    = 43 findings to apply

Only these 43 findings are shown in Editor Review!

ROLE-BASED ACCESS
────────────────────────────────────────────────────────────────────────────────

COPYEDITPM Role:
  ✓ Can upload manuscripts
  ✓ Can select rules in Discovery
  ✓ Can save selections
  ✓ Can manage their own selections
  ✓ Can review findings in Editor
  ✗ Cannot see other users' selections

ADMIN Role:
  ✓ Can do everything COPYEDITPM can do
  ✓ Can view all users' selections
  ✓ Can modify/delete any selection
  ✓ Can view all analysis results

================================================================================

PERSISTENCE & REUSABILITY
────────────────────────────────────────────────────────────────────────────────

Session-Based (Discovery):
  • Saved in: /manuscript_results/<session_id>/
  • Lifetime: Until cleanup
  • Use: Current analysis session only

Database-Saved (Rule Selections):
  • Saved in: rule_selections table
  • Lifetime: Persistent (you control when deleted)
  • Reuse: Can use same selection for multiple jobs

  Example Reuse:
  ───────────────
  1st Job: WKH_Ch1-11
     → Create selection: "WKH_Pataki_Essential"
     → Save to database

  2nd Job: WKH_Ch12-15
     → Go to /manuscript/rule-selections
     → Activate "WKH_Pataki_Essential"
     → No need to re-select! Already configured!

  3rd Job: Another WKH project
     → Activate "WKH_Pataki_Essential"
     → Done!
